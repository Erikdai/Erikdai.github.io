I read a lot of papers and write a lot of scratch notes that never leave my local machine. This page is an attempt to keep the useful ones somewhere I can link to — mostly paper notes on LLM reasoning, multi-agent systems and retrieval, plus the occasional writeup of something that broke and how I fixed it.

Nothing here is meant to be polished. If a note turns out to be wrong, I would rather leave it up with a correction than quietly delete it.

我平时读论文和做实验会记很多零散笔记，但基本都躺在本地。这里就是把其中值得留下来的部分放出来：主要是 LLM 推理、多智能体系统和检索相关的论文笔记，偶尔也写写踩坑记录。

写得不精致是常态。如果哪条笔记后来发现是错的，我会在原文上更正，而不是删掉。
